# Excelデータクリーナー

取引先から届くExcelデータを、Python / pandasで自動的に整形・チェックするツール。

## 課題

取引先のExcelには以下のような表記ゆれや不正データが含まれる。

- 列名の余分な空白
- 売上日の形式の違い
- `-`、`不明` などの日付不正値
- `3,000円` などの金額表記
- 商品コード・売上日・金額の欠損

これらを毎月手作業で修正している想定。

## Pythonで自動化する処理

1. Excelを読み込む
2. 列名を整える
3. 売上日を正規化する
4. 金額を正規化する
5. 不正データを検出する
6. 正常データとエラーデータに分ける
7. Excelとして出力する

## 処理フロー

```text
売上データ.xlsx
      ↓
Python / pandas
      ↓
データ正規化・エラーチェック
      ↓
├── cleaned_売上データ.xlsx
└── errors_売上データ.xlsx
```

## 現在のチェック項目

- 商品コードが存在するか
- 売上日が正しいか
- 金額が正しいか
- 複数エラーがある場合はすべて記録する
